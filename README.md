# 🌍 Travel Planner

A modern Flutter application to organize every aspect of a trip.

> Built with Flutter, Riverpod, Isar and Clean Architecture.

---

# ✨ Features

## Trips

- Create and manage trips
- Trip dashboard
- Progress tracking

## Timeline

- Add, edit and delete stops
- Timeline visualization
- Categories
- Geocoding support

## Maps

- Interactive OpenStreetMap
- Markers
- Route visualization
- Navigation
- Search locations

## Budget

- Expense tracking
- Categories
- Budget dashboard
- Statistics
- Remaining budget
- Progress indicator

# 🚀 Getting Started

Clone

```bash
git clone https://github.com/YOUR_USERNAME/travel_planner.git
```

Install

```bash
flutter pub get
```

Generate Isar files

```bash
dart run build_runner build --delete-conflicting-outputs
```

Run

```bash
flutter run
```
